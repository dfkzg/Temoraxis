# С чего начать

## Сегодня можно проверить приложение без сервера

1. На Android откройте `releases/temoraxis-android.apk`. Минимум — Android 8.0 и актуальный Android System WebView/Chrome.
2. В старом HTML-планёре экспортируйте JSON, а в приложении импортируйте его через настройки. Ссылки Start_page переносятся её собственным экспортом/импортом.
3. Включите напоминания в настройках. Разрешите Android-уведомления и точные напоминания через меню приложения `⋮`.
4. Создайте задачу на несколько минут вперёд, включите напоминание и проверьте его при свёрнутом приложении и заблокированном экране.
5. Проверьте кнопку «Выполнено» в уведомлении. После открытия приложения должна быть выполнена эта дата; будущие повторения должны оставаться.
6. Проверьте экспорт JSON: Android предложит выбрать место сохранения файла.

Это тестовый APK. На реальном телефоне его ещё нужно проверить. Системные напоминания используют системный звук Android; свои аудиофайлы пока доступны для прослушивания внутри приложения.

## Когда будет выбран сервер

Ничего не куплено и не опубликовано. Серверная часть, Docker-конфигурация и инструкция находятся в комплекте. Для размещения понадобятся VPS, домен и HTTPS. Полные шаги — в `README.md`, раздел 3.

После размещения:

- В APK откройте настройки синхронизации, укажите HTTPS-адрес и создайте аккаунт по коду приглашения.
- На ПК откройте этот же сайт и войдите в тот же аккаунт.
- Друг с iPhone открывает сайт в Safari, создаёт отдельный аккаунт и добавляет сайт на экран «Домой». Платная лицензия Apple для PWA не нужна.
- Если на двух устройствах появились разные изменения, интерфейс предложит выбрать версию; старая локальная копия сохраняется для восстановления.

В этой версии синхронизация выполняется при открытом приложении. После изменения задач на ПК откройте APK и синхронизируйте его, чтобы обновились Android-напоминания. Фоновых push-уведомлений iPhone пока нет.

Не удаляйте старую рабочую копию планёра и JSON-бэкап до переноса и проверки данных. Сервер не заменяет резервную копию.
