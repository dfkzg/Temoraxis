Temoraxis

Windows 11 x64: запустите temoraxis-windows.exe. Нужен WebView2 Runtime.
Закрытие окна оставляет приложение в трее; полный выход — через меню трея.
Данные: %LOCALAPPDATA%\Temoraxis. Замена EXE не удаляет их.
Напоминания требуют запущенного приложения; при сне компьютера не гарантируются.
EXE без сертификата издателя: возможно предупреждение Windows SmartScreen.

Android: установите temoraxis-android.apk поверх прежней версии.
ПК: распакуйте архив и откройте planner.html или Start_page.html.
Локальные HTML сохраняют данные в браузере. Регулярно делайте экспорт JSON.
Для общего хранилища страниц, синхронизации и веб-уведомлений рекомендуем:
https://dfkzg.github.io/Temoraxis/app/planner.html
Фоновые будильники доступны в APK при выданных разрешениях.
Исходники: https://github.com/dfkzg/Temoraxis
Инструкция: https://dfkzg.github.io/Temoraxis/guide.html
