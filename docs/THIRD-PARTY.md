# Сторонние компоненты и происхождение ресурсов

Этот перечень разделяет материалы приложения, файлы репозитория и внешние инструменты. Наличие copyright-уведомления означает указание правообладателя; удаление уведомлений не делает компонент собственным кодом проекта.

## Интерфейс и ресурсы приложения

- Исходные `planner.html` и `Start_page.html` созданы пользователем с помощью DeepSeek. Дальнейшие изменения выполнялись с помощью ChatGPT/Codex. Подробности и ограничения проверки: [PROVENANCE.md](PROVENANCE.md).
- Статические SVG-кнопки в текущем `web-source/planner.html` заново заданы геометрическими примитивами в ходе этой разработки, с помощью ChatGPT/Codex, без загрузки контуров из набора иконок. Это не утверждение о самостоятельном написании учеником.
- В прежних версиях контура `check-square` найдено точное совпадение с Feather Icons. Для учёта происхождения и прежних копий сохранены [полная MIT-лицензия и уведомление Cole Bemis](licenses/Feather-MIT.txt). Источник: https://github.com/feathericons/feather. Текущие статические контуры заменены, но это не изменяет старые коммиты и ранее скачанные APK.
- `web-source/icon.svg` — простой геометрический знак проекта, присутствующий с начальной загрузки исходников. PNG 180/192/512 в текущей версии воспроизводимо создаются из этого SVG нашим скриптом `tools/generate_app_icons.py` на стандартной библиотеке Python. Внешние растровые изображения не используются. Совпадение рисунка с каким-либо изображением во всём интернете этим не исключено.
- Android launcher — векторная версия того же геометрического знака. Значок уведомления в текущей версии задан заново; готовый контур из библиотеки не импортируется.
- Файлы шрифтов, музыкальные записи и фотографии в исходниках интерфейса не поставляются. Шрифты берутся из системы, фоновый будильник использует системную мелодию Android. Пользовательские аудиофайлы и фоновые картинки, добавленные после установки, остаются ответственностью их загрузившего пользователя.
- Названия и адреса сторонних сайтов в экспресс-панели являются ссылками, а не копиями их сайтов или логотипов.

## Серверное окружение и CI

Docker-конфигурация использует `python:3.12-slim` и `caddy:2`. Их образы и входящие компоненты имеют собственные лицензии и уведомления, которые сохраняются в дистрибутивах. Caddy — Apache-2.0: https://github.com/caddyserver/caddy/blob/master/LICENSE. Описание образа Python: https://hub.docker.com/_/python. Эти образы не являются содержимым Android APK.

GitHub Actions подключаются по закреплённым коммитам из workflow и выполняются отдельно в CI; их код не становится автоматически кодом Android-приложения. При самостоятельном распространении образов или инструментов нужно сохранять уведомления именно тех дистрибутивов, которые распространяются.

## Облачная синхронизация

Supabase используется как внешний сервис Auth и PostgreSQL по опубликованному HTTP API: https://supabase.com/docs . Клиентский транспорт написан для проекта с помощью ChatGPT/Codex на стандартном fetch; готовый Supabase SDK в приложение не копируется. PostgreSQL 17 в Docker применяется для тестов SQL-схемы, его бинарные файлы в APK и исходники не входят; условия PostgreSQL: https://www.postgresql.org/about/licence/ .

## Резервное копирование — внешние инструменты

В `tools/backup/` используются стандартная библиотека Python, HTTP API Google Drive, Яндекс Диска и OAuth 2.0; Google/Yandex SDK и чужие реализации OAuth в проект не копируются. Для шифрования workflow устанавливает **age** из пакета Ubuntu (BSD-3-Clause; https://github.com/FiloSottile/age/blob/main/LICENSE), для логического дампа использует `pg_dump`/`pg_restore` из `postgres:17-alpine` (PostgreSQL License и лицензии компонентов образа; https://www.postgresql.org/about/licence/). Бинарные инструменты не включаются в APK или архив исходников. В тестах используется age 1.2.1 из официального выпуска; Actions использует версию age из репозитория Ubuntu 24.04.

## Версия для Windows 11

Windows-оболочка проекта использует Microsoft .NET / Windows Forms (MIT и уведомления включённых компонентов) и Microsoft Edge WebView2 SDK 1.0.2903.40 (условия Microsoft, файл LICENSE.txt из NuGet-пакета). Лицензии восстановленных пакетов встраиваются в EXE и доступны через меню трея «Лицензии». WebView2 Runtime устанавливается отдельно на условиях Microsoft; его бинарные файлы в комплект проекта не включаются. EXE содержит локальный веб-интерфейс из тех же исходников, что Android и сайт.
