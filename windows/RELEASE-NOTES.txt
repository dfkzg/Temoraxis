Первая версия Temoraxis для Windows 11 x64.
Отдельное окно, работа без интернета, общее хранилище планёра и экспресс-панели, синхронизация с аккаунтом телефона.
Закрытие окна сворачивает приложение в трей; меню трея позволяет открыть окно или полностью выйти.
Данные хранятся в %LOCALAPPDATA%\Temoraxis и сохраняются при замене EXE.
Требуется Microsoft Edge WebView2 Runtime. Если он отсутствует, приложение предложит официальную страницу установки.
Напоминания доступны только при работающем приложении, в том числе в трее; во время сна компьютера, после полного выхода и до запуска они не гарантируются.
EXE не подписан платным сертификатом: Windows SmartScreen может показать предупреждение о неизвестном издателе. Скачивайте файл с официальной страницы проекта и проверяйте контрольную сумму.
