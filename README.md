# Temoraxis

Планёр с задачами, календарём, расписанием дня и напоминаниями.

**[Скачать приложение](https://dfkzg.github.io/Temoraxis/)** · Android 8.0 и новее

**[Открыть веб-планёр](https://dfkzg.github.io/Temoraxis/app/planner.html)** · ПК и мобильный браузер

## Начало работы

1. Скачайте APK и установите приложение. Обновления устанавливайте поверх текущей версии.
2. При первом запуске пройдите настройку разрешений для уведомлений, будильников и работы в фоне. Напоминания в настройках уже включены.
3. Создайте задачу, задайте время и включите для неё напоминание.

Если будильник не срабатывает, откройте **Настройки → Тест системы**.

## Данные и синхронизация

Задачи сохраняются на устройстве и доступны без интернета. Перенести данные можно через **Настройки → Экспорт всех данных / Импорт**. Перед удалением приложения сохраните копию.

Облачная синхронизация проходит настройку. После запуска войдите в один аккаунт на телефоне и в веб-планёре: **Настройки → Синхронизация → Облако Temoraxis**.
