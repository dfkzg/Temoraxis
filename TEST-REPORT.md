# Проверки версии 0.1.1 · 14 ноября 2026

## Android-пакет

- APK собран из Java-кода и локальных HTML-ресурсов.
- Пакет `ru.personal.planner`, версия `0.1.1`, versionCode `2`.
- Минимальная версия Android: API 26 / Android 8.0. Target/compile API: 35.
- Сборка: Android Build Tools 35.0.0, OpenJDK 21, Eclipse ECJ 3.39.0.
- `apksigner verify --verbose`: подписи v2 и v3 действительны.
- Проверены manifest, стартовая Activity, разрешения и наличие `classes.dex`.
- HTML, manifest, service worker и PNG-иконки внутри APK побайтово совпадают с проверенными файлами `server/web`.
- Есть одно предупреждение компилятора о совместимом, но deprecated Android API `setDecorFitsSystemWindows`; ошибок компиляции нет.

## Проверки Android-логики без устройства

`ReminderCalculatorTest.java` выполнен на JVM с реальным JSON-java:

- время напоминания с упреждением;
- исключение слишком старого события;
- ежедневные и еженедельные повторения;
- выбранные дни недели;
- выполнение отдельной даты;
- повторный сигнал через заданный интервал;
- остановка напоминаний отдельной даты;
- отложенный старт серии;
- часовой пояс устройства, включая Europe/Moscow.

Браузерный тест с имитацией Android-моста проверил отправку расписания, получение отметки «Выполнено», элементы разрешений, экспорт JSON через Android API и выбор звуков. Он не заменяет запуск APK на телефоне.

## Сервер

Четыре автоматических теста `tests/test_server.py` прошли:

- регистрация по приглашению, вход, выход и отзыв токена;
- изоляция двух аккаунтов;
- чтение только с авторизацией;
- optimistic concurrency: устаревшая ревизия даёт 409;
- два одновременных обновления одной ревизии: одно проходит, второе получает конфликт;
- проверка Origin/CORS и отклонение опасных URL ссылок;
- база и исходники не доступны через статические маршруты.

## Сценарии в Chromium / Playwright 1.62.1

`tests/run_browser_tests.py` поднимает временный локальный сервер и отдельную SQLite-базу, выполняет сценарии и останавливает сервер.

Пройдены:

1. Вход одного аккаунта с двух независимых устройств/контекстов.
2. Передача задач, отметок повторений и удаления.
3. Одновременные изменения: конфликт без потери локальной версии; загрузка сервера, восстановление локальной копии и явная отправка.
4. Смена аккаунта: данные предыдущего аккаунта не отправляются новому без явного выбора; новый аккаунт может начать с пустой копии.
5. Android-мост: расписание передаётся сразу после изменения задачи; нативная отметка выполнения применяется к своей дате; экспорт вызывает системный API.
6. PWA: обе страницы доступны из кэша без сети; API-ответы в кэш не попадают.
7. Незавершённая форма не перезаписывается входящими данными.
8. Открытая панель задачи обновляется без скрытия и повторного появления.

Дополнительно пройдены проверки прежнего интерфейса на итоговой веб-версии: покраска часов, шаблоны, сохранение, звуки и громкость, импорт/экспорт JSON, напоминания, повторы и подзадачи по датам, просроченные задачи, fullscreen-форма, автоскрытие меню и удаление задачи/серии.

## Повторить проверки

```
python stage_web.py
python tests/test_server.py
npm ci
npx playwright install chromium
python tests/run_browser_tests.py
```

JVM-тесты правил напоминаний:

```
python tests/run_native_tests.py --json-jar PATH/TO/json-20240303.jar
```

Понадобятся JDK и JSON-java 20240303. Для JRE без javac можно добавить `--compiler-jar PATH/TO/ecj-3.39.0.jar`. JAR-файлы инструментов не включены в комплект.

## Фоновый будильник 0.1.7

Добавлена foreground-служба mediaPlayback с системным звуком будильника, циклическим воспроизведением до 60 секунд, wake lock на время звука и остановкой из уведомления. Расписание использует AlarmClock при разрешённых точных будильниках; без разрешения остаётся неточный вариант. Сборка Android и проверки расчёта расписания проходят. Выключенный экран, очистка недавних приложений и ограничения батареи на реальном телефоне требуют повторной проверки пользователем; эмуляции устройства здесь не было.
